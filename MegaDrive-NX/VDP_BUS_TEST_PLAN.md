# MegaDrive-NX VDP / bus diagnostic, next test

## Evidence
Switch photo (2026-11-22): FRAMES=1, PIXELS=0, VDP=0, CPU clock 1332 MHz, RATE ~38191, runtime 1224s. The CPU MHz is the Switch hardware frequency; RATE is simulated master-cycle throughput, not game FPS. Values do not prove chip correctness.

## Immediate test protocol
1. Use the same ROM, region and build for every run; capture a 10-second baseline. Record ROM header checksum, reset vector, CPU PC, last bus address and RATE.
2. Sample a bounded ring buffer (64 entries) of 68000 bus events with address, data, R/W, AS, UDS/LDS, DTACK and reset. Do not print every event on-screen or to disk. Dump only on pause or exit.
3. Record FC1004 select/ack/ready transitions, Z80 BUSREQ/RESET state, and writes to 0xC00000-0xC0001F. Count actual VDP control/data writes separately.
4. Check whether VDP control writes configure display, DMA and VRAM. Trace the first 16 writes and scanline transitions. Compare against the same ROM's known-good trace.
5. Only after writes are confirmed, add an isolated synthetic VDP test pattern (palette, tile, sprite, scrolling). Label it SYNTHETIC TEST: it must not be mistaken for output generated by the ROM.
6. Keep diagnostic sampling disabled during normal benchmarking. Compare baseline and instrumented versions at identical clocks and settings.

## Decision table
- No 68000 bus activity: reset/vector/CPU clock fault.
- 68000 bus activity but no FC1004 handshake: bus decode/arbitration fault.
- Handshake present but no VDP writes: ROM initialization or missing acknowledge.
- VDP writes present but no scanline/pixels: VDP register/VRAM/renderer pipeline.
- Pixels present but wrong image: tile, palette, sprite or timing error.

## Constraints
Never inject an unconditional DTACK or skip ROM instructions to make the game advance. Do not describe the Switch program as physical FPGA hardware. The pinned Nuked-MD chip combination is not a literal production Mega Drive PCB. A successful synthetic graphics test validates only the display pipeline, not Super Hang-On boot or game accuracy.
